# UI — fonts and glyphs

Fonts are free Google Fonts (SIL Open Font License 1.1), baked into static SDF TextMesh Pro atlases by `Desync.UI.Editor.UISetup`.
Licence texts are kept in `DESYNC/Assets/Fonts/Licenses/`. No AI-generated art or audio; all UI sprites are generated procedurally at runtime.
